# XXD Panel 023｜东方窗形柔光框景生成核心

只处理当前任务明确提供的一张源照片。锁定一个主体或不可拆分关系、主要动作，以及至少三个源图专属线索。不得借用样张、旧成品或其他输入的主体、窗形、光色、文案与构图。

## 窗形必须由源图决定

从圆窗、花窗、漏窗、月洞、扇形窗、六角窗或简化几何棂格中，只选择一种最适合源图轮廓、动作方向、开口、重心与空间关系的框景结构。不得机械套用固定月洞门，也不得堆叠多种传统纹样。

主体、枝影、光斑或抽象投影必须在窗形中显现、穿过、遮挡或轻微溢出，使窗框同时承担秩序、前后层次与虚实转换。窗形可偏置、局部裁切或悬置，不必居中；但必须形成一个主要光区、一个安静留白区和少量柔和投影构成的稳定视觉三角。

## 源图取色的浅底与生命光

背景从源图提取一个极浅、低饱和、干净的综合色，例如雾蓝、浅青、淡杏、柔粉、灰绿、暖米白或极浅紫灰。它必须保持轻、亮、通透，并与主体形成温柔而清楚的明度落差。禁止固定深蓝、脏灰、厚重暗底、荧光色或生硬高反差。

从源图最有生命力的颜色提炼柔和光色，可适度提亮和提纯，形成克制的冷暖呼应。色光只服务主体、窗影、情绪与空间，不形成廉价滤镜或任意彩虹渐变。

## 柔焦喷绘与漫射投影

使用细腻喷绘颗粒、色粉、空气感柔焦、粉尘与漫射光。光影边缘自然虚化并轻微晕染；窗格可比光影略清晰，但仍柔和，不做硬质建筑描边。画面应像阳光穿过传统窗棂投在浅色墙面，又被空气与记忆轻轻模糊。

保持主体与源图清晰对应，但拒绝卡通轮廓、写实厚涂、3D体积、硬边矢量、复杂装饰、过度对称、平均铺满和模板居中。

## 023 文字系统

自动文案从源图可见或有依据的情绪、时间、动作、温度或隐喻中提炼一个极短标题，并按需加入少量地点词、状态词或微型短句。地点、日期、出处和事实编号必须由用户提供或可靠确认，不得为了高级感伪造。

文字沿窗框边缘、弧线、轴线或光影留白形成对齐、环绕、错位或穿插。使用当地文字系统中自然的极小字号、细字重与安静编辑节奏；不得把拉丁宽字距、旋转或环排机械套用到中文、日文、韩文或阿拉伯文。用户准确文案逐字保留；无文字模式不出现任何文字或伪文字。

## 模式与硬性验收

严格服从附加的 `OUTPUT MODE`、`FINAL SIZE` 与 `DESIGN FRAME`。双联模式只生成设计半幅；纯设计与壁纸不显示原照片。每张壁纸按设备重新构图，不裁切其他设备成果，不绘制系统 UI 或设备模型。连贯壁纸共同参考原照片与同一张已批准定调图，绝不串联衍生图。

硬性验收：一种由源图形态决定的传统窗形；主体或投影与窗形发生显现、穿过、遮挡或溢出；至少三个源图线索与主要动作仍可辨；一个主要光区＋一个安静留白＋少量柔投影形成视觉三角；源图提取的极浅低饱和背景与生命光色；细腻喷绘颗粒、色粉、空气柔焦和漫射边缘；窗格略清晰但不硬；极短标题与少量微文字进入窗沿、弧线、轴线或光影留白；无深重暗底、脏灰、荧光、硬反差、卡通、廉价滤镜、复杂纹样、写实厚涂、3D、模板居中或伪文字。

若任一硬性条件失败，纠正生成资产，不要用程序绘图、SVG、HTML、Canvas 或后期文字覆盖伪造成品。
